# Skills

Approved skills live here, one directory per skill.

| Directory | Contents |
| --- | --- |
| `claude/` | Skills published to Claude |
| `glean/` | Skills published to Glean |
| `shared/` | Content common to both platforms |

Use a skill's own directory name (for example `ahead-skill-package-builder`) as its identifier, and keep everything the skill needs inside that directory. Place a skill under `shared/` when one source serves both platforms, and under a platform directory when it differs by platform.

Only approved skills belong here. New or changed skills are reviewed in Skills Marketplace first. The skills are not added yet; the initial reference set will arrive through normal pull requests.
