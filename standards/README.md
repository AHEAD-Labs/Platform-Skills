# Standards

The AHEAD skill standard is owned and maintained with Skills Marketplace. It defines the quality expectations for a skill, such as structure, formatting, and consistency.

This repository does not copy that standard, so there is only one version to keep current. Refer to the current standard through Skills Marketplace or the Enterprise GPT team.

Add a short note here only when this repository needs a rule of its own, such as a layout convention for `skills/`.
